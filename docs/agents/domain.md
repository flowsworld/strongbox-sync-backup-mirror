# Domain docs

This repository uses a single, central set of domain docs:

- `CONTEXT.md` in the repository root for terminology.
- `docs/adr/` for architecture decisions.

Before exploring the code, read the existing `CONTEXT.md` and the ADRs that
relate to the topic. If they do not exist, continue without asking.
These files are created only when there is a concrete need.

Use the defined terms in code, issues, and proposals.
Clarify missing terms during a later domain modeling session.
Name any conflict with existing ADRs explicitly.
