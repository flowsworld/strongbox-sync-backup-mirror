# Triage labels

The roles map one to one to the label names:

| Label | Meaning |
|---|---|
| needs-triage | Needs evaluation |
| needs-info | Waiting on an answer to a question |
| ready-for-agent | Specified well enough for an agent to work on alone |
| ready-for-human | Needs a human to implement |
| wontfix | Will not be done |
